# Akasha RECORD

Static portfolio website for GitHub Pages.

## Preview
Open `index.html` in a browser. No build process or dependencies.

## Update content
- Edit text and sections in `index.html`.
- The profile icon and character reference are stored in `assets/images/`. Replace the remaining work placeholder SVG and update image paths in `index.html`.
- Replace the non-clickable SNS placeholders with real `<a href="https://...">` links when URLs are confirmed.
- Theme settings are in `css/style.css`, interactions in `js/main.js`.

## Publish
Push these files to `main`. In repository Settings → Pages, select Deploy from a branch, `main`, `/ (root)`, then Save. Expected project URL: `https://akasha-nopperi.github.io/akasha-record-site/` after deployment succeeds.
